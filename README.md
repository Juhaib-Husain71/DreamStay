# DreamStay 🌍🏕️

DreamStay is a full-stack travel accommodation listing platform inspired by modern vacation rental websites. It allows users to discover beautiful stays, view detailed property pages, and manage listings with a clean, responsive interface.

## ✨ Features

* User authentication with login, signup, and logout
* Create, edit, and delete property listings
* Browse stays with attractive card-based UI
* Detailed listing pages with images, location, price, and amenities
* Secure form handling and validation
* Image upload and storage using Cloudinary
* Flash messages for better user feedback
* MongoDB database integration for persistent data storage

## 🔐 Authentication

DreamStay includes user authentication so only logged-in users can create, edit, or delete their own listings. Protected routes help ensure secure access to sensitive actions.

## 🧪 Validation & Security

* Server-side validation using Joi
* Secure authentication flow
* File upload restrictions
* Error handling middleware
* Flash alerts for success and failure messages
